# 速知 SecKnow

一个给中小学生用的学习陪伴小项目：把每个知识点做成 10 分钟的小探险，学完有一只像素宠物跟着长大。它不会因为几天没来就死掉或退化，只会想你、等你回来。

前端是 React 18 + TypeScript + Vite 5，样式用 Tailwind CSS 3，动画用 Framer Motion，数据暂时存在浏览器 localStorage 里。

## 跑起来

```bash
npm install
npm run dev
```

然后打开 `http://localhost:5173/`。仓库根目录就是前端工程，不用再进一层 `app/`。想验证构建跑 `npm run build`，产物在 `dist/`；`npm run preview` 可以预览构建结果。

## 里面有什么

首页是产品介绍，点「领取我的小伙伴」进应用。第一次进来可以选猫头鹰、青蛙，或者开个盲盒随机抽（青蛙小时候是蝌蚪）。

宠物有蛋、幼年、成年三个阶段，靠经验值升级；心情和饱腹度会随时间慢慢降，但有下限，不会归零。抚摸、喂食、说说话都能跟它互动，它平时会眨眼、左右看、偶尔蹦一下。

学习是「探究 → 阅读 → 测试」三步，一个知识点三道选择题。答错也给经验，答对给得多一些，连续学几次还有小奖励。拿到的经验会加到宠物身上，学习记录里能翻到每次的学科、答对题数和时间。

左下角的「🛠 调试面板」是我自己验收时用的：加经验、改状态、模拟离开 24/72 小时、重置数据。演示的时候用它加速比较方便——正常玩要学五次左右才能到成年。

想改数值（升级阈值、奖励、衰减速度）都在 `src/config/config.ts`。宠物长什么样在 `src/components/character/Character.tsx`，是一张字符画矩阵，改字符就能换造型和配色。

## 现在还差什么

课程只放了 5 个示例知识点，没接账号和云端，数据只在这台浏览器里；时间衰减那块是靠调试面板模拟验证的，没真的挂机跨天测过。后面接题库和登录就能继续往下做。
